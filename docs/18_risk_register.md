# リスク管理表

| ID | リスク | 影響 | 対策 |
|---|---|---|---|
| R-001 | AIへ機密情報を送信する | 情報漏えい | 入力検査、警告、マスキング、MVP制限 |
| R-002 | APIキーが漏えいする | 外部不正利用、課金被害 | Cloudflare Secret、ログ出力禁止、再表示禁止 |
| R-003 | AIが誤った整理をする | 誤判断 | 人間確認を必須化 |
| R-004 | AIコストが増える | 予算超過 | 利用上限、月間予算、緊急停止 |
| R-005 | Slack議論が正本化されない | 決定漏れ | 意思決定記録へ反映する運用 |
| R-006 | 権限設定ミス | 不適切な閲覧・操作 | Cloudflare Access、ロール管理、監査 |
| R-007 | Slack通知失敗 | 周知漏れ | 通知失敗ログ、再送、手動共有 |
| R-008 | Neon障害 | 登録不可 | 障害表示、復旧後再実行 |
| R-009 | プロンプト変更で品質低下 | 出力不安定 | プロンプトバージョン管理、テスト |
| R-010 | 現場利用者が入力を難しく感じる | 利用定着しない | ウィザード形式、例示、下書き保存 |
