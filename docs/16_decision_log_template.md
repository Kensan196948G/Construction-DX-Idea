# 意思決定記録テンプレート

## 1. 業務判断記録

```markdown
# Decision: <決定タイトル>

- 日付:
- 対象アイデア:
- 決定者:
- 関係者:
- 決定内容:
- 決定理由:
- AI提案との差異:
- セキュリティ確認:
- 次のアクション:
```

## 2. ADRテンプレート

```markdown
# ADR-000: <技術判断タイトル>

## Status

Proposed / Accepted / Deprecated / Superseded

## Context

背景と制約を書く。

## Decision

決定内容を書く。

## Consequences

利点、欠点、今後の影響を書く。
```

## 3. 記録対象

- AIプロバイダー選定
- Secret管理方式
- DB設計の主要変更
- MVP範囲の変更
- ステージ定義の変更
- セキュリティ方針の変更
- 本番化判断
