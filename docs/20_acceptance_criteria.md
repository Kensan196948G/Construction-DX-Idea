# 受入基準一覧

## 1. MVP受入基準

| ID | 基準 |
|---|---|
| AC-001 | Cloudflare Access経由で認証された利用者だけがWebUIへアクセスできる |
| AC-002 | 利用者が困りごと、現行手順、改善したい状態を入力できる |
| AC-003 | 機密情報候補を検出した場合に警告を表示できる |
| AC-004 | AIが不足情報を最大3問程度提示できる |
| AC-005 | AIが指定項目へ構造化できる |
| AC-006 | 利用者がAI結果を修正できる |
| AC-007 | 利用者が下書き保存できる |
| AC-008 | 利用者が正式登録できる |
| AC-009 | 正式登録後にSlackへ通知される |
| AC-010 | 管理者がステージを変更できる |
| AC-011 | AI処理履歴にモデル、文字数、成否、プロンプトバージョンが記録される |
| AC-012 | APIキー本体がレスポンス、DB、ログに出力されない |
| AC-013 | AI機能を管理者が無効化できる |
| AC-014 | 利用上限到達時にAI実行が停止される |
| AC-015 | 重要操作が監査ログに残る |

## 2. セキュリティ受入基準

- 一般利用者はAI接続設定画面を開けない。
- 未認証のAPI直接呼び出しは401で拒否される。
- 一般利用者によるAI接続設定、監査ログ、ステージ変更APIの直接呼び出しは403で拒否される。
- Cloudflare Access JWTの署名、audience、issuer、有効期限が検証される。
- 保存済みAPIキーは再表示されない。
- APIキーは末尾4文字のみ表示される。
- 接続テスト失敗時にキーは保存されない。
- AIへ送信する前に禁止情報候補の検査が行われる。

## 3. 運用受入基準

- Slack通知失敗時もアイデア登録は成功する。
- AI障害時に下書き保存と既存アイデア閲覧ができる。
- AI利用量を利用者別・機能別に確認できる。
- 管理者がAI機能を緊急停止できる。
