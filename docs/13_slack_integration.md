# Slack連携仕様書

## 1. 役割

Slackは入力場所ではなく、システムからの通知と関係者間の議論に利用する。

## 2. 通知対象

- 新規アイデア登録通知
- コメント・検討依頼
- ステージ変更通知
- 承認依頼
- MVP公開通知
- 検証開始・完了通知
- 週次ダイジェスト
- Construction-DX-Ideaへのリンク

## 3. 新規登録通知

含める情報:

- アイデアタイトル
- 対象業務
- 課題要約
- 期待効果
- 登録者
- 詳細ページリンク

含めない情報:

- 機密情報候補
- APIキー
- AIとの会話全文
- 未マスキング原文

## 4. ステージ変更通知

含める情報:

- 変更前ステージ
- 変更後ステージ
- 変更者
- 変更理由
- 詳細ページリンク

## 5. 議論の反映

Slack上の議論で決まった内容は、自動的な正本とはしない。担当者がConstruction-DX-Ideaへ意思決定記録として登録する。

## 6. 障害時

Slack通知に失敗しても、アイデア登録自体は成功とする。通知失敗はログに記録し、必要に応じて再送する。
