# AIプロンプト・処理設計書

## 1. AIの役割

AIは整理、質問生成、分類、要約、MVP案作成を支援する。採用、却下、セキュリティ判定、本番化判断は行わない。

## 2. AI処理種別

| 処理 | 目的 |
|---|---|
| questions | 不足情報を最大3問生成 |
| structure | 会話内容を構造化 |
| classify | 業務分類、DX分類の候補作成 |
| summarize | Slack通知や一覧向け要約 |
| mvp | MVP候補と終点の提案 |

## 3. 共通制約

- 個人情報、案件固有情報、契約金額、認証情報を求めない。
- 不明な点は推測せず未確認事項へ入れる。
- 業務上の最終判断を断定しない。
- AI回答は利用者確認前に正式登録しない。
- プロンプトはバージョン管理する。

## 4. 質問生成プロンプト方針

AIに渡す情報:

- マスキング済み困りごと
- 既に回答済みの情報
- 質問済み項目
- 禁止情報リスト

出力:

- 最大3問
- 各質問の目的
- 回答形式の候補

## 5. 構造化プロンプト方針

出力項目:

- アイデア名候補
- 現在の課題
- 対象業務
- 対象利用者
- 現行手順
- 改善案
- 期待効果
- 必要データ
- 関連システム
- 実現方式候補
- セキュリティ上の注意
- 未確認事項
- MVP候補
- MVPの終点

## 6. プロンプトバージョン

命名例:

- `questions_v1`
- `structure_v1`
- `summary_v1`
- `mvp_v1`

AI処理履歴には必ず使用したプロンプトバージョンを保存する。

## 7. 品質確認

AI出力に以下が含まれる場合は、正式登録とSlack通知へ進めない。利用者に修正または再生成を求め、再検査で問題が解消された場合だけ保存処理へ進める。

- 個人名らしき文字列
- メールアドレス
- 契約金額
- 未公開事故情報
- 断定的な採用・却下判断
- セキュリティ上の最終判定

AI品質確認ログには検出種別、件数、処理結果、モデル、時刻を保存する。APIへ送信したプロンプト全文、AI応答全文、検出された機密情報の原文は保存しない。
