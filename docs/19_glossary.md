# 用語集

| 用語 | 定義 |
|---|---|
| 困りごと | 現場や業務で発生している不便、非効率、二重入力、共有漏れなど |
| DXアイデア | 困りごとを改善するためのデジタル活用案 |
| AI壁打ち | AIが不足情報を質問し、利用者が回答しながら内容を整理する過程 |
| 構造化 | 自由記述を課題、対象業務、改善案、期待効果などの項目へ整理すること |
| MVP | Minimum Viable Product。検証に必要な最小構成の試作品 |
| MVPの終点 | MVPで何ができれば検証完了とするかの条件 |
| Cloudflare Access | Webアプリの入口を保護する認証・認可サービス |
| Cloudflare Workers | エッジ上でAPI処理を実行する基盤 |
| Cloudflare Secret | Workersから参照する機密情報の保存先 |
| Neon PostgreSQL | PostgreSQL互換のマネージドDB |
| Claude API | AIによる質問生成、整理、分類、要約に使うAPI |
| Slack通知 | 登録やステージ変更を関係者へ共有する通知 |
| 監査ログ | 誰が、いつ、何をしたかを記録するログ |
| プロンプトバージョン | AIへ与える指示文の版数 |
| 正本 | 判断や記録の正式な保存先 |
