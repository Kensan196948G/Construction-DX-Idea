# コスト・レート制限設計書

## 1. 方針

APIキーが1本でも、システム側で利用者ごとの利用回数、文字数、再生成回数、月間予算を制御する。

## 2. 制限項目

| 項目 | 初期値例 |
|---|---:|
| 1人あたり日次AI実行回数 | 10回 |
| 1回あたり入力文字数 | 2,000文字 |
| 1アイデアあたり再生成回数 | 5回 |
| 同時実行数 | 低めに制限 |
| 月間予算警告 | 管理者設定 |
| 月間停止上限 | 管理者設定 |

## 3. 利用量記録

記録項目:

- 利用者
- 機能
- 処理種別
- モデル
- 入力文字数
- 出力文字数
- 実行日時
- 成否
- 概算費用

## 4. 上限到達時

- AI機能を停止する。
- 手動入力と下書き保存は継続する。
- 管理者へ通知する。
- 監査ログへ記録する。

## 5. 緊急停止

管理者はAI機能を即時無効化できる。無効化後、AI質問生成、構造化、要約、MVP案作成は実行不可とする。
