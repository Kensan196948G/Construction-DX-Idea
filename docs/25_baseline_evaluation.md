## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| プロジェクト名 | Construction-DX-Idea（AI活用型DXアイデア管理システム） |
| 目的 | 土木建設業務の困りごとをWebUIで収集し、AIとの壁打ちで整理・構造化し、DXアイデアとして登録・評価・進捗管理する |
| 主な利用者 | 現場（現場代理人・主任技術者・測量・事務担当）、本社IT/DX部門、経営層、協力会社（将来） |
| 技術スタック | React 19 + Vite / Cloudflare Workers + Hono / Neon PostgreSQL / Claude API / Slack Webhook / GitHub Actions |
| 認証 | Cloudflare Access（JWT署名・issuer・audience・exp検証） |
| 規模前提 | 従業員約600名、IT/DX部門7名、公共工事80％・民間工事20％ |

## 2. 業務課題と提供価値

- 業務課題: 現場の困りごとが口頭・メール・Excelで散逸し、DX候補の棚卸し・評価・進捗管理が属人化する。
- 提供価値: AIが構造化する入力ウィザードにより、非エンジニアでも「困りごと」をDXアイデアとして登録でき、管理者がステージ管理・評価・CSV出力できる。
- 基本方針: 入力・AI整理・進捗管理は本システム、周知・議論はSlack。AIは最終判断をしない（人間確認必須）。

## 3. 完成段階・運用段階

- 完成段階: MVP完了（2026-07-21 Production Ready、2026-07-28 AI有効化）。2026-08-09にソース正本復元とIssue #14永続化を実施。Phase 2（検証版）の一部（評価ボードAPI・CSV・検索・履歴API）はAPIのみ本番反映済み。
- 運用段階: 本番稼働中（`phase_mode=maintenance`）。ただし実利用者数・利用実績は ideas 0件（2026-07-28保守時点）であり、実業務での定着は未検証。
