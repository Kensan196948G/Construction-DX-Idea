# MVPスコープ・ロードマップ

## 1. MVPスコープ

MVPでは、困りごと入力、AI壁打ち、構造化、利用者確認、正式登録、Slack通知、ステージ管理、AI利用量・監査ログを提供する。

## 2. MVP対象機能

1. Cloudflare Accessによるログイン
2. 困りごとの入力
3. 入力検査・匿名化
4. AIによる追加質問
5. AIによるアイデア構造化
6. 利用者による修正・確定
7. Neonへの下書き・正式登録
8. アイデア一覧・詳細表示
9. 管理者によるステージ変更
10. Slackへの新規登録通知
11. AI使用量・監査ログ
12. AI機能の有効・無効設定
13. 接続状態・利用上限の管理

## 3. MVP対象外

- Slackからのアイデア登録
- 複数AIプロバイダーの本格対応
- 添付ファイル原文のAI解析
- 自動採否判定
- 自動セキュリティ承認
- 高度なダッシュボード分析

## 4. 段階導入

| 段階 | 内容 |
|---|---|
| Phase 0 | 文書化、要件確定、プロトタイプ |
| Phase 1 MVP | 入力、AI整理、登録、Slack通知 |
| Phase 2 検証版 | 管理画面、利用上限、評価フロー強化 |
| Phase 3 運用版 | Secrets Store、複数管理者、ローテーション |
| Phase 4 拡張 | 複数AI、分析、研究利用、既存システム連携 |

## 5. MVP完了条件

複数利用者がWebUIから困りごとを入力し、Claude APIによる整理結果を本人が確認・修正して正式登録できること。登録結果がSlackへ通知され、管理者がアイデアの検討ステージを管理できること。

## 6. 保守フェーズ・プロダクト拡張ロードマップ（2026-07-28確定）
